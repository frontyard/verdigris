# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report
vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/frontyard/verdigris/security/advisories/new)
for this repository.

Include enough detail to reproduce the issue: the affected version or
commit, the configuration involved, and the observed behavior. We aim to
triage reports within a few days and will keep you updated through the
advisory thread.

## Supported versions

Security fixes are applied to `main` and released with the next tagged
release. Only the latest release and `main` are supported.

## Scope and bounties

Verdigris is a volunteer-run open source project: there is no monetary
bounty program. We are happy to credit reporters in release notes and the
resolving advisory when a report leads to a fix.
